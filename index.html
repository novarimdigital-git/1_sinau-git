Cheat Sheet & Panduan Pribadi

Belajar Git dari Nol sampai Mahir

Dokumentasi lengkap hasil praktik alur kerja Git, GitHub, Branching, hingga pengelolaan banyak file.

1 Konsep Inti & Tiga Status Git

Git bekerja menggunakan sistem snapshot (foto kondisi project) bukan perubahan baris, serta membagi file ke dalam tiga status utama:

1. Modified

File di komputer sudah diubah/diedit, tetapi belum disimpan ke database Git lokal.

2. Staged

File yang sudah dimodifikasi ditandai dan disiapkan untuk masuk ke checkpoint berikutnya (git add).

3. Committed

Data/snapshot tersimpan permanen sebagai checkpoint di database lokal (git commit).

2 Setup Awal & Identitas

# Atur identitas agar commit atas nama Anda sendiri

git config --global user.name "novarim"

git config --global user.email "emailanda@example.com"

# Mulai repository baru di folder project

git init

3 Siklus Kerja Harian & Pengelolaan Banyak File

Urutan perintah harian serta cara menangani banyak file/folder sekaligus:

# 1. Cek file yang berubah

git status

# 2. Masukkan SEMUA file & folder sekaligus ke staging area

git add .

# (Opsional) Pilih file spesifik / jenis file tertentu:

git add index.html style.css # Beberapa file khusus

git add *.html # Berdasarkan ekstensi file

git add gambar/ # Semua files dalam folder gambar

# 3. Buat checkpoint / simpan permanen di lokal

git commit -m "Pesan keterangan perubahan"

# 4. Unggah checkpoint ke GitHub (Cloud)

git push

4 Manajemen Branch & Sinkronisasi Tim

Membuat & Berpindah Branch Eksperimen:

git checkout -b fitur-baru

Menggabungkan Branch ke Jalur Utama (Merge):

git checkout main
git merge fitur-baru
git push origin main

Menghapus Branch yang Gagal/Batal:

git branch -D fitur-baru # Lokal
git push origin --delete fitur-baru # Cloud

Mengambil Pembaruan dari Tim (Pull):

git pull
